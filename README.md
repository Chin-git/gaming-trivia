# The Ultimate Gaming Trivia Challenge

A six-question gaming trivia website with a secret animated ring-box finale and an engagement photo gallery.

## Run locally
Extract the ZIP and open `index.html` in Chrome. No installation or server is required.

## Publish on GitHub Pages
1. Create a repository with a neutral name such as `gaming-trivia-challenge`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Share the published URL.

## Customize
Edit the `rounds` array in `script.js` to change the six questions, answers, and hints. The four photos in `assets/reveal1.jpg` through `assets/reveal4.jpg` are shown only after the final box is opened during normal gameplay.

## Privacy / spoilers
The home page, page title, description, questions, and footer do not disclose the engagement. The engagement pictures and reveal text are still accessible to anyone who inspects the publicly hosted source files. GitHub Pages does not conceal website assets.
